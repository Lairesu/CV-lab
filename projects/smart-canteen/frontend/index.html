How does this prototype work?

An administrator currently sets table statuses manually. FastAPI saves those updates in SQLite, and this page checks for changes every five seconds. Separately, the admin editor saves camera table zones in SQLite, and YOLO has been tested on recorded video and sample person detections. Automatic occupancy decisions have not been connected to this dashboard. Unknown means availability has not been verified.
